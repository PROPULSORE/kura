# Contributing to Kura

Thank you for wanting to help. Kura is free to use, but its source code is
**closed**: this repository only holds the releases and the public documents.
For this reason **pull requests with code are not accepted**.

You can still help a lot.

## Report a bug

1. Check the [open issues](https://github.com/PROPULSORE/kura/issues) first:
   someone may have reported it already.
2. [Open a bug report](https://github.com/PROPULSORE/kura/issues/new?template=bug_report.yml)
   and fill in the form: the Kura version, the device and system, what you did,
   what you expected and what happened instead.
3. If you can, attach the **diagnostics log**:
   - open **Profile › Diagnostics** in Kura;
   - **read it first**: it removes keys, tokens, cookies and the recovery code,
     but it does show the titles and the website addresses involved;
   - remove anything you do not want to share, then **Copy** it or **Save to a
     file**, and paste or attach it to the issue.

Problems with a specific extension or website are usually for the author of
that extension: Kura does not make or distribute extensions.

## Suggest an idea

[Open a feature request](https://github.com/PROPULSORE/kura/issues/new?template=feature_request.yml)
and explain what you would like to do and why. One idea per issue, please.

## Translations and texts

Kura is in English and Italian. Corrections to existing texts, or the wish to
help with another language, are welcome as issues.

## Security

Do not report security problems in public issues. See [SECURITY.md](SECURITY.md).

## Language

Issues can be written in English or Italian.
